# PinPad SDK — Guía para Claude Code

SDK de Android de Clip para procesamiento de pagos (Terminal SDK app-to-app y Server Side SDK). Módulo principal: `pinpad-sdk/`. Distribución vía JitPack.

## Contexto entre sesiones

**IMPORTANTE:** Lee `PROJECT_CONTEXT.md` al inicio de cada sesión — contiene la finalidad del proyecto, cambios realizados, decisiones, pendientes y repos involucrados.

Al terminar trabajo relevante (cambios, decisiones, nuevos pendientes), **actualiza `PROJECT_CONTEXT.md`** para que la siguiente sesión pueda recuperar el contexto.
